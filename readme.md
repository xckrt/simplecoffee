# Simple Coffee Learning Portal

Репозиторий серверной части (API): [https://github.com/xckrt/simplecoffeeAPI](https://github.com/xckrt/simplecoffeeAPI)

Корпоративная образовательная платформа, разработанная для автоматизации процессов обучения, аттестации и информирования сотрудников сети кофеен Simple Coffee. Проект представляет собой полноценное веб-приложение (SPA) с разделением на клиентскую часть и серверный API.

## Основной функционал

* **База знаний:** Интерактивные обучающие модули, разбитые по темам (от ботаники кофе до психологии сервиса) с встроенными проверочными мини-тестами.
* **Справочник меню:** Полный каталог напитков и позиций кухни с детальным описанием состава, метода приготовления и показателей КБЖУ.
* **Система тестирования:** Модуль итоговой аттестации сотрудников с ограничением по времени и автоматическим расчетом проходного балла.
* **Панель управления (Manager):** Инструментарий для мониторинга результатов тестирования, управления списком сотрудников и редактирования контента базы знаний.
* **Личный кабинет:** Просмотр истории прохождения тестов и текущего прогресса обучения.
* **Безопасность:** Полноценная авторизация на базе JWT-токенов с разграничением прав доступа (Manager, Barista, Trainee).

## Стек технологий

### Backend
* **Runtime:** .NET 8.0
* **Framework:** ASP.NET Core (Web API)
* **ORM:** Entity Framework Core
* **Database:** PostgreSQL
* **Authentication:** JWT (JSON Web Token)

### Frontend
* **Core:** Vanilla JavaScript (без использования тяжелых фреймворков для максимальной производительности)
* **Architecture:** SPA (Single Page Application) с кастомным роутингом
* **Styling:** Modern CSS3 (CSS Variables, Flexbox, Grid)
* **Icons:** Feather Icons / FontAwesome

### Deployment
* **Web Server:** Nginx (Reverse Proxy)
* **OS:** Linux (Ubuntu/Debian)
* **Process Manager:** Systemd units

## Архитектурные особенности

1.  **Проксирование запросов:** Веб-сервер Nginx настроен на разделение трафика: статические файлы фронтенда раздаются напрямую, а запросы к `/api/` перенаправляются на локальный порт работающего .NET-приложения.
2.  **База данных:** Использование PostgreSQL обеспечило высокую скорость работы со сложными связями (вопросы/ответы тестов) и поддержку современных типов данных.
3.  **Мобильная адаптация:** Интерфейс полностью оптимизирован под мобильные устройства (Mobile-first) для удобного использования сотрудниками непосредственно на рабочем месте в кофейне.
